# Weather Widget ☁️

A lightweight, embeddable weather widget that displays real-time weather information for any city using the OpenWeatherMap API.

## Features
- 🔍 Search weather by city name
- 🌡️ Displays temperature in Celsius
- 💧 Shows humidity percentage
- 💨 Shows wind speed
- 🎨 Clean, compact widget design
- ⚡ Fast and lightweight

## Technologies Used
- HTML5
- CSS3  
- JavaScript (ES6)
- OpenWeatherMap API
